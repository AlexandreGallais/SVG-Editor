# Playbook

How to run a software project with a coding agent (Claude Code) and a Product Owner who questions rather than codes — written from this project, reusable for the next ones. Updated at every epic retrospective (ADR-0023); each rule says where it comes from.

| Page                             | Content                                               |
| -------------------------------- | ----------------------------------------------------- |
| [principles.md](./principles.md) | the rules that make agent-written code trustworthy    |
| [setup.md](./setup.md)           | bootstrapping a new repository: checklist, in order   |
| [process.md](./process.md)       | backlog, research, audit, demo, review, retrospective |
| [agent.md](./agent.md)           | configuring and steering the agent                    |
| [lessons.md](./lessons.md)       | what went wrong, and the check that now prevents it   |

To start a new project: read the five pages, then follow [setup.md](./setup.md); copy files from this repository rather than rewriting them, and keep the links to the ADRs that justify them.
